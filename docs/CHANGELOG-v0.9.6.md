# MedTrak+ v0.9.6 – Purchase Orders and Mobile Purchasing Visibility

## New

- Added a Purchase Order detail view in the Purchasing module.
- Added copy-to-clipboard order text for purchase orders.
- Added email supplier action using the supplier ordering email where available.
- Added full line-item visibility in purchase order detail, including barcode, SKU, ordered quantity and received quantity.
- Added mobile purchasing summary cards for pending reorder requests and orders awaiting delivery.
- Updated mobile reorder flow to show supplier/SKU information and use standard order quantity where set.

## Improved

- Removed temporary mobile low-stock debug alert.
- Updated mobile branding from Aurora Mobile to MedTrak+ Mobile.
- Kept desktop and mobile purchasing workflows aligned.

## Notes

This build does not yet perform stock-updating goods receipt. Goods receiving will be handled in a later build so partial delivery, batch, expiry and barcode checks can be designed properly.
